---

Ferryx is an ultra-lightweight, native Rust terminal host daemon built on Tauri v2. It gives you split-pane tiling, an embedded web companion for browser tabs alongside your terminals, and authenticated mobile remote control so you can reach your sessions from a paired device.

## Split-Pane Tiling

Arrange terminal panes in flexible vertical and horizontal splits within a workspace, with pointer-driven resizing and smooth layout transitions.

## Embedded Web Companion

Open browser tabs directly alongside your terminal tabs in the same workspace, backed by the native webview.

## Mobile Remote Control

Pair a mobile device with your running Ferryx daemon to view and steer terminal sessions remotely.

See the [keyboard shortcuts](/docs/shortcuts/) reference for the in-app bindings.

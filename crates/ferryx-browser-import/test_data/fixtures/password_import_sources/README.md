# Password import source fixtures

These are sanitized synthetic fixtures for `.omo/plans/maho-password-manager-product-plan.md` Task 4. They encode documented/public user-export formats only: 1Password CSV fields, 1PUX ZIP container entries (`export.attributes`, `export.data`), Bitwarden individual/organization CSV headers, Bitwarden JSON, Apple Passwords/Safari-style CSV, and KeePass/KeePassXC CSV variants.

No file in this directory is a real export, no live password-manager database was read, and every credential value is a synthetic `SYNTH-*` marker for leak checks.

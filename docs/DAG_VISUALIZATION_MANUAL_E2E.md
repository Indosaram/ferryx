**작성:** 2026-08-29 · **상태:** 초안 (Wave 2 이후 실제 UI 기준으로 최종 갱신 예정)
**실행자:** 사용자 (데스크톱 자동화 금지 규칙에 따라 에이전트가 직접 수행하지 않음)

## 사전 조건

- [ ] 데스크톱 실행은 정확히 `bun tauri dev` (debug 전용, 바이너리 직접 실행·.app 복사 금지)
- [ ] `bun run --cwd ui dev` Vite 개발 서버가 켜져 있어야 함 (debug 번들은 devUrl 로딩)
- [ ] 데스크톱 실행 전 기존 데몬 종료 권장 (PTY 레벨 변경은 데몬 재시작이 필요할 수 있음)

## E2E 시나리오

### 1. 활동 배지로 진입 (우측 상단)

- [x] omo에서 dag가 실행 중이면 **윈도우 우측 상단에 그래프 모양 배지가 나타나고 빛나며(pulse) 깜빡인다**
- [x] 실행 중인 런이 없으면 배지는 숨겨진다
- [x] 배지 클릭 → 우상단 팝오버에 실행 중 런 목록(상태 글리프 + 진행률)과 선택한 런의 라이브 그래프가 표시된다
- [x] 여러 프로젝트/워크트리에서 동시에 돌아가는 dag도 모두 인식한다 (프로젝트 루트 + 워크트리 경로별 감시)

### 1b. DAG 패인 (전체 그래프)

- [x] 런이 없을 때 빈 상태 문구("No dag runs yet")가 표시된다
- [x] 감시 중인 프로젝트의 기존 런 목록이 자동 로딩된다 (`dag_watch_project`)

### 2. 실시간 런 추적

- [ ] 터미널 패인에서 실제 `mass-ulw` 실행 (예: 작은 2~3노드 작업 지시)
- [ ] DAG 패인에 런 헤더가 나타난다: `이름 — wave k/n — X/Y done, R running`
- [ ] wave 열(column)이 의존성 순서대로 표시된다 (열 = wave)
- [ ] 노드 카드에 상태 글리프가 보인다: ▶ running / ✓ completed / ✗ failed / ◌ pending
- [ ] `scheduled ◔ → running ▶ → completed ✓` 전환이 실시간으로 반영된다 (≤2초 지연)

### 3. 강조 요소

- [ ] critical path 노드·엣지가 액센트 색으로 틴트된다
- [ ] bottleneck 노드에 `blocks N` 배지가 보인다
- [ ] running 노드에 펄스 애니메이션, 완료 시 green, 실패 시 red

### 4. 완료·에러 상태

- [ ] 런 완료 시 헤더 카운트가 `Y/Y done`으로 갱신된다
- [ ] 실패 노드 카드가 red로 표시된다 (에러 코드 확인은 마우스 오버/상세)

### 5. 팬 트리 통합 회귀

- [ ] DAG 패인을 분할/드래그로 이동해도 렌더링이 유지된다
- [ ] 터미널·브라우저 패인과 혼용 시 기존 동작에 회귀 없음 (레이아웃 직렬화 후 복원 포함)
- [ ] 앱 재시작 후 DAG 패인이 레이아웃에서 복원된다

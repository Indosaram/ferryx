**Overall verdict: PASS (Zero Actionable Blockers)**

All 8 mandatory verification criteria are fully verified via executed real scenarios and preserved artifacts:
1. **Three Hosts & Kinds Matrix:** Assembly strictly enforces exactly 3 hosts (`macbook`, `omaki`, `maho-win`) and binds permitted kinds (`macbook`: `macos-updater`, `dmg`; `omaki`: `appimage`, `deb`; `maho-win`: `msix`, plus `nsis` iff `channels.nsisMigration: true`). Missing any receipt, unauthorized host-kind binding, or duplicate kinds aborts assembly.
2. **Identity Binding:** Receipt `commitSha`, `appVersion`, `runId` must strictly equal release plan values, and `exitCode` must be 0. Any skew or non-zero exit code fails closed.
3. **Exact Field Validation & No Credential Storage:** Both release plans and host build receipts enforce `schemaVersion: 1`, reject unexpected keys (including fake hosted schema URLs like `$schema`), and strictly reject credential/secret fields (`privateKey`, `token`, `authHeader`).
4. **Real Cryptographic Minisign Verification:** Updater artifacts (`macos-updater`, `appimage`, `nsis`) require authentic Minisign Ed25519 signatures. Both Blake2b-512 payload signatures and global trusted-comment signatures are validated via `verifyMinisign` against the public key. Tampered data, corrupted signatures, or altered trusted comments fail closed.
5. **Filesystem Jail & Traversal Prevention:** Relative paths (`relPath`, `signatureRelPath`) reject `..` traversal and null bytes. Inode resolution via `realpathSync` confirms all files reside strictly inside `artifactsDir`, trapping external symlinks before copy or staging.
6. **Collision-Free Deterministic Stable Aliases:** Exact inventory payloads and signatures are published alongside canonical stable aliases (`Ferryx_universal.dmg`, `Ferryx_universal.app.tar.gz`, `Ferryx_amd64.AppImage`, `Ferryx_amd64.deb`, `Ferryx_x64.msix`, and `Ferryx_x64-setup.exe` if migration). Target collisions and duplicate claims abort assembly.
7. **Checksum Closure & Manifest Pre-Creation:** `latest.json` is generated FIRST (pub_date derived from `sourceDateEpoch`). `SHA256SUMS.txt` hashes 100% of published files, explicitly including `latest.json`. Validated with `shasum -a 256 -c`.
8. **Atomic Staging & Fail-Closed Publication:** Sibling staging directory `.staging-<basename>-<hex>` isolates work. Pre-existing `outDir` aborts before staging. Verification errors clean up staging directory and leave zero published or partial files. Legacy CLI arguments fail with exit code 2.

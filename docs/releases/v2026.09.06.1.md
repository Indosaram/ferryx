## What ships in this release

- **Hourly in-app update checks** (`ac6d0f6`): the update check previously ran only once at app startup, so releases published while the app was open never showed their toast. Now the app polls every hour (chain-based timer, generation-guarded stop, overlap-skipping while an update is offered/installing).
- **Windows Store migration notice** (`fd72688`): installer-channel Windows builds show a one-time, dismissible notice that the NSIS installer is deprecated and to reinstall from the Microsoft Store. Backed by `cmd_distribution_channel` (`store` / `installer` / `native`).
- **English changelogs**: GitHub release bodies are maintained in English.

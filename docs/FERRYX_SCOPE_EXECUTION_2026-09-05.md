## 1. Scope and decisions
- Deliver A1 global waiting/unread inbox; A2 SSH settings/Run on/persistent remote worktree+PTY; A3 conversation search/read/resume.
- Deliver Design element/rectangle selection, actual viewport pixels, DOM/CSS, preview/note, explicit local/remote agent delivery.
- Deliver C1 create/list/start/prompt/read/wait/stop/events; C2 managed Codex chat/approvals/questions/files/drafts; C3 independent host/task management; C4 genuine background push/task return.
- Exclude PR/checks/CI failure logs/GitHub/Linear, Git GUI/editor/diff review, schedules/dev services/usage/hibernation/plugins, voice, CloudVM, E2EE relay, artifact-sharing service and shortcut redesign. None is a prerequisite.
- Initial historical providers: Codex and Claude only, independently gated list/read/search/resume capabilities. Other providers explicitly show Unsupported; their existing terminals remain usable.
- Structured chat: daemon-owned portable `codex app-server --listen stdio://`, newline JSON-RPC, tested initially against 0.153.2. Claude remains terminal-only; never infer approval cards from text.
- SSH: system OpenSSH -> fixed `ferryx-remote-helper bridge --stdio` -> remote persistent headless daemon. Disconnect kills only bridge, never the PTY daemon. No local SSH PTY masquerading as survival.
- Helper manually installed, version-matched, on reachable hosts; no auto-install/provisioner. Build targets: macOS arm64/x64, Linux x64/arm64, Windows x64; unsupported builds fail visibly, never run locally.
- Capture uses WKWebView takeSnapshot, WebView2 CapturePreview and WebKitGTK get_snapshot platform adapters. Unsupported runtime/API returns CAPTURE_UNSUPPORTED with explanation, not a synthetic PNG.
- Push uses maintained vetted Rust `web-push` library, locked exact reviewed version/features, no hand-rolled crypto. Dependency review precedes manifest changes; unavailable/unacceptable library blocks push shipping, not other producers.
- HTTPS deployment: operator-managed trusted reverse proxy to existing gateway, same-origin HTTPS/WSS, no relay. QA may use existing approved Tailscale Serve HTTPS; do not install or configure infrastructure silently.
- UI: existing controls, semantic theme tokens, dense shell, native masks, keyboard/focus/Escape, selectable history, visible error/empty/loading/unsupported states. No framework/UI dependency installs.

## 2. Frozen shared contracts (integration owner publishes before producer RED)
- `TargetRef = {hostId, ownerId, epoch, backendSessionId}`; epoch is canonical decimal string of u64, never JS number. Host/owner identify durable host and daemon owner; epoch changes on runtime replacement.
- Workspace/worktree/tab/leaf are navigational attributes, never process identity. Routing resolves full TargetRef, validates current epoch and membership, and never falls back to active desktop selection or another pane.
- `RunTarget = {kind:"local"}|{kind:"ssh",hostId}` persisted per project; absent old value migrates Local. Worktree inherits immutable target. Host deletion disables references, not remote processes.
- Inventory snapshot `{revision,items,completeness:"complete"|"partial"|"unknown",unavailableHosts}` plus ordered retained transitions `{revision,target,kind,source}`. Subscribe atomically with snapshot/cursor; lag returns explicit resync/gap.
- Waiting is provider/request state or qualified terminal detection with provenance; unread is independent per-client acknowledgment. Only provider-confirmed turn completion emits taskComplete; working->idle alone never does.
- One claim registry keyed by host + canonical provider + provider-authored conversation ID spans native resume and managed chat. Claim acquisition/spawn/release is atomic; pending thread creation has provisional request ownership.
- Native TUI and managed app-server may not own one conversation concurrently. Explicit handoff stops/releases previous owner, confirms exit, then resumes same provider ID; failed handoff stays stopped/error, never launches a second owner.
- Managed chat's terminal view is a read-only rendering of that same managed event stream, not a second Codex TUI. Switching to interactive native TUI requires the explicit handoff; transcript/request identity survives reconnect, not uncommitted provider approvals after ownership transfer.
- Add capability negotiation to daemon v3 with additive messages; feature clients reject missing `scopeControlV1`/`sshHelperV1`/`managedCodexV1`/`captureV1`. Existing v3 terminal paths remain compatible; legacy inventory explicitly incomplete.
- Remote auth reuses device tokens; View allows list/read/events, Control additionally creates/starts/prompts/stops/answers/uploads/resizes. Check global allow_control, current token/revoke and target scope on every mutation and live socket frame.
- One explicit renewable control/resize lease per target; conflict => CONTROL_CONFLICT. Revoke cancels streams/leases and deletes push subscriptions immediately. Read-only navigation stays independent for desktop and each phone.
- Mutation envelope `{requestId,target?,params}`; cache operation+canonical payload+result per owner epoch (persist worktree creation dedupe with task record). Identical retry returns receipt; different payload => REQUEST_CONFLICT; uncertain epoch retry => TARGET_EXPIRED.
- Results `{ok:true,data,requestId}` or `{ok:false,error:{code,message,retryable,details},requestId}`. HTTP 400 validation, 401 token, 403 permission, 404 missing, 409 conflict/stale, 413 size, 422 unsupported, 504 timeout.
- Codes include INVALID_REQUEST, UNAUTHORIZED, FORBIDDEN, NOT_FOUND, TARGET_EXPIRED, CONTROL_CONFLICT, REQUEST_CONFLICT, PROVIDER_OWNED, UNSUPPORTED, TIMEOUT, INVENTORY_INCOMPLETE; errors remain actionable, not swallowed.
- Events `{sequence,target,revision,type,data}`; resume afterSequence with explicit gap snapshot. `wait` subscribes before action or reads retained events; timeout is explicit, not inferred completion. Stop is idempotent cancellation of exact target.
- Attachments: integration-owned host-scoped staging service; 10 MiB/file, 4 files/turn, 20 MiB total, PNG/JPEG/WebP/text/PDF with signature/type checks. Canonical private jail, opaque attachmentId, hash/size receipt, no arbitrary path requests or symlink escapes.
- Stage atomically at target host under `.ferryx/design-feedback/<id>.png` for Design (private app staging for other files); remote transfer uses helper bytes, then hash verification. Reject unsupported provider media before delivery.
- Draft freezes TargetRef, browser generation, attachment hashes and note at confirmation. Submit once with requestId; receipt distinguishes staged/accepted/provider-read (last requires real evidence). Cancel/failed upload preserves draft; cleanup unreferenced files after 24h using injected clock tests.
- Draft storage `ferryx.chatDraft.<encoded-full-target>` contains unsent text and attachment receipts only; revoked device clears protected drafts. Never put tokens/local paths/transcript bodies in push or shared evidence.

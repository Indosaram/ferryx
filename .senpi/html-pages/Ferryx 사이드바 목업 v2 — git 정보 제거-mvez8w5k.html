1이름 클릭 = 선택만 — 이미 펼쳐진 프로젝트 이름을 눌러도 접히지 않습니다. 접기는 chevron만 담당합니다.
2활성 행 = 배경 톤 + 레일 — 회색 테두리와 hex 값을 없애고 worktree-sidebar-accent 배경으로 표시합니다. 왼쪽 가이드 레일이 활성 행에서만 밝아집니다.
3한 줄 행 — 이름과 상태 슬롯 하나만 둡니다. 브랜치, 변경 수, primary 배지 같은 git 정보는 모두 뺐습니다. 원격 호스트만 오른쪽에 작게 남깁니다. idle 점은 표시하지 않습니다.
4hover 버튼 2개로 축소 — +와 ⋯만 남깁니다. 휴지통과 History는 ⋯ 메뉴 / 우클릭 메뉴로 옮깁니다.
5필터 필드 — 프로젝트·worktree 이름과 브랜치로 바로 좁힐 수 있습니다.
6Worktrees / Inbox 세그먼트 — 지금 보고 있는 모드가 항상 보입니다. 아이콘 pressed 상태로만 알던 것을 대체합니다.
7푸터는 실제 의미로 — "12 sessions watched" 대신 실행 중·입력 대기 수를 보여 줍니다.

①은 클릭 동작이라 그림에는 표시하지 않았습니다.

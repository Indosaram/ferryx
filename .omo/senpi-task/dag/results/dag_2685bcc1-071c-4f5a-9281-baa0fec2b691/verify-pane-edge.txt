### 1. Git Diff Scope

The pane-edge and drag-and-drop implementation touches the following core UI and state management files:

- `ui/src/components/TerminalSplitView.tsx`: Integrated `PaneEdgeDropZones` into `PaneLeafView`, added draggable handle metadata (`sourcePaneId`, `sourceSessionId`), and implemented drop command dispatching for `move-pane-to-pane-split` and `move-tab-to-pane-split`.
- `ui/src/components/tab-dnd/PaneEdgeDropZones.tsx`: Renders directional edge drop targets (`left`, `right`, `top`, `bottom`) per leaf pane.
- `ui/src/components/tab-dnd/SplitEdgeDropZone.tsx`: Droppable component for split zones with pointer styling and layout anchors.
- `ui/src/components/tab-dnd/tabDragTypes.ts`: Added `PaneEdgeDropData`, `move-tab-to-pane-split`, and `move-pane-to-pane-split` command definitions with priority weighting (`pane-edge` prioritized ahead of `group-edge`).
- `ui/src/state/tabPaneDrop.ts`: Pure tree transformation helper `moveTabIntoPaneSplit` that splices subtrees into target leaf nodes and remaps colliding leaf IDs while preserving session instances.
- `ui/src/state/workspaceStore.ts`: Added `MOVE_TAB_TO_PANE_SPLIT` action handling in reducer and exposed `targetPane` argument in `moveTabToSplit`.

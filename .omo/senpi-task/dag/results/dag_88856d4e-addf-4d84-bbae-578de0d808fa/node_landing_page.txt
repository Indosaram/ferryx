The Ferryx landing page has been updated with multi-platform direct download capabilities and platform-aware UI components.

### Summary of Changes
1. **Platform Configuration & Asset Endpoints (`site/src/lib/downloads.ts`)**:
   - Configured direct download endpoints targeting the latest GitHub release assets (`https://github.com/Indosaram/ferryx/releases/latest/download/...`):
     - **macOS**: Apple Silicon (`Ferryx_aarch64.dmg`), Intel (`Ferryx_x64.dmg`), Universal (`Ferryx_universal.dmg`).
     - **Windows**: Direct standalone NSIS setup (`Ferryx_x64-setup.exe`), MSIX package (`Ferryx_x64.msix`), and Microsoft Store link (`https://apps.microsoft.com/detail/ferryx`).
     - **Linux**: Standalone AppImage (`Ferryx_amd64.AppImage`) and Debian package (`Ferryx_amd64.deb`).
   - Added client-side platform detection (`detectUserPlatform`).

2. **Interactive Platform Dropdown & Icons (`site/src/components/DownloadMenu.tsx`, `site/src/components/ui/PlatformIcons.tsx`)**:
   - Implemented `DownloadMenu` component providing an auto-detected OS quick download button alongside an interactive popover selector for all platform binaries and architectures.
   - Added SVG platform icons for Apple, Windows, Linux, and Microsoft Store.

3. **Landing Page Component Integration**:
   - **Hero (`site/src/components/Hero.tsx`)**: Added platform-detected primary download button with architecture dropdown, direct platform download links (`macOS`, `Windows`, `Linux`), and a direct link to GitHub releases.
   - **CTA / Direct Downloads Section (`site/src/components/CTA.tsx`)**: Built a 3-column multi-platform download grid presenting dedicated cards for macOS, Windows, and Linux with all available binary formats and architecture details, plus source build quickstart.
   - **Navbar (`site/src/components/Navbar.tsx`)**: Integrated compact download menu dropdown and direct navigation links.
   - **Mock Core (`site/src/mock/core.ts`)**: Provided Tauri `Channel` mock to ensure clean site builds when resolving shared UI types.

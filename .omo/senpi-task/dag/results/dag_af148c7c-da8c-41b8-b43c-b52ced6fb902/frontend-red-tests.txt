### Summary of Regression Tests

Deterministic failing-first frontend regression tests were implemented for Ferryx's reported bug: worktrees lacking independent tab/session isolation and multi-workspace session saving clobbering inactive registered workspaces.

No production source files were modified; only allowed test files were changed.

From `ui`:
```bash
bun test src/state/workspaceStore.test.tsx src/lib/sessionPersistence.test.ts src/App.test.tsx
```

### Test Names & Root Causes

1. **`worktree tab and session isolation > maintains independent tabs and sessions per worktree when switching between worktrees`**
   - **File**: `ui/src/state/workspaceStore.test.tsx`
   - **Root Cause Proved**: In `ui/src/state/workspaceStore.ts`, the layout state (`state.layout.tabs`, `tabGroups`, etc.) is maintained globally for the workspace instead of being isolated per worktree. When `openTab` or `SELECT_WORKTREE` is triggered for a different worktree, `SELECT_WORKTREE` only modifies `state.activeWorktreePath` and does not isolate or restore independent tab lists per worktree. As a result, selecting worktree B leaves worktree A's tabs in `state.layout.tabs` (received 3 tabs instead of 1).

2. **`worktree tab and session isolation > isolates browser tabs to the worktree in which they were created`**
   - **File**: `ui/src/state/workspaceStore.test.tsx`
   - **Root Cause Proved**: Browser tabs added via `createBrowserTab` append directly to `state.layout.tabs` without scoping to the active worktree. Switching to another worktree continues to render the browser tab in the active tab set.

3. **`App project workspace flow > preserves every registered workspace when saving session instead of clobbering inactive workspaces`**
   - **File**: `ui/src/App.test.tsx`
   - **Root Cause Proved**: In `ui/src/App.tsx`, both auto-save and window close guard (`registerWindowCloseGuard`) serialize only `activeProject.workspaceId` via `serializeWorkspaceState`, constructing `{ workspaces: { [activeProject.workspaceId]: workspace } }`. Saving does not merge or retain inactive preloaded workspaces (such as workspace `alpha`), causing `saveSession` to overwrite and clobber previously saved workspaces on app lifecycle events.

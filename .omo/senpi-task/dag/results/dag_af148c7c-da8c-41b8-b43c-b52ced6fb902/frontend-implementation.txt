### Summary of Modified Behavior

1. **Worktree-Isolated Tab and Layout State (`ui/src/state/workspaceStore.ts`, `ui/src/lib/types.ts`)**:
   - `WorkspaceState` now maintains `worktreeLayouts?: Record<string, LayoutState>` storing inactive worktree layouts while `state.layout` represents the active worktree's complete layout.
   - Worktree selection (`SELECT_WORKTREE`) atomically preserves the outgoing worktree layout in `worktreeLayouts` and restores or initializes the target worktree layout in `state.layout`.
   - Terminal and browser tabs are assigned to the target `worktreePath` captured when tab creation was initiated, even if active worktree selection changes concurrently.
   - `ensureTabForWorktree` checks active and parked layouts for existing tabs before creating replacements.
   - Project-global sessions, agents, and activity summaries properly traverse both active and parked layouts.

2. **Session Persistence & Deserialization (`ui/src/lib/sessionPersistence.ts`, `ui/src/lib/types.ts`)**:
   - `serializeWorkspaceState` serializes both active layout and parked `worktreeLayouts`, emitting sessions referenced across all worktree layouts while omitting unreferenced sessions.
   - Browser tabs serialize and deserialize their full metadata (`profileId`, `worktreePath`, `worktreeLabel`, URL, and navigation state).
   - `deserializeWorkspaceState` compatibly restores legacy flat layouts as well as multi-worktree layouts with per-worktree layout trees and tab groups.
   - Preserves dead-session respawn records (`backendSessionId: null`, `lifecycle: "exited"`, `cwd`, `worktreePath`, `worktreeIdentity`).

3. **Workspace Session Merge & Startup Restore (`ui/src/App.tsx`)**:
   - `App.tsx` merges the active project's serialized workspace into existing persisted workspaces (`existingSession.workspaces`) instead of overwriting inactive workspace entries.
   - Serializes auto-saves and close guard writes through a sequential promise chain (`saveChainRef`) to prevent stale save races after selection changes.
   - Boot restoration checks both active layout and parked layouts, restoring all worktree sessions and re-spawning dead terminal sessions across all worktrees.
   - Replaced inline arrow callbacks for `onOpenSettings` and `onCloseSearch` with stable handlers.

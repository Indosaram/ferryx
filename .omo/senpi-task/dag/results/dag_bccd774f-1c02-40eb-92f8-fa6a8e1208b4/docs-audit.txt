# Ferryx Repository Documentation & Root Markdown Audit

## (a) Verified Project Name and Purpose

* **Canonical Name**: **Ferryx** (`ferryx`)
* **Bundle Identifier**: `com.ferryx.app`
* **Evidence**:
  * `package.json:2` (`"name": "ferryx"`)
  * `src-tauri/Cargo.toml:2,7` (`name = "ferryx"`, `name = "ferryx_lib"`)
  * `src-tauri/tauri.conf.json:3-5` (`"productName": "Ferryx"`, `"identifier": "com.ferryx.app"`)
  * `PRODUCT.md:1-51` & `BRANDING_AND_ICON_SPECIFICATION.md:6-10`
* **Core Purpose**:
  Ferryx is an ultra-lightweight, zero-Electron, native desktop workspace and AI agent launcher built on Rust (Tauri v2) and React 18 / Vite / xterm.js WebGL. It is engineered for parallel AI agent development (Claude Code, Codex, Gemini CLI, etc.) with sub-150ms startup and <85MB idle RAM.
* **Core Capabilities**:
  1. **Native Rust PTY Host**: Direct OS pseudoterminal allocation with sub-millisecond I/O and daemon session persistence.
  2. **Multi-Agent Workspace**: Native split-pane tiling with real-time agent status detection (`working`, `waiting`, `done`, `unread`) and tab icons.
  3. **Embedded Browser Companion**: Side-by-side native child webview tabs with Fast Refresh and local dev loopback.
  4. **Mobile Web Remote Connection**: Built-in HTTP/WebSocket remote server with pairing code authentication for steering sessions from mobile browsers over LAN/Tailscale.
  5. **Session Persistence**: Durable workspace and layout serialization across application restarts and crash recovery.

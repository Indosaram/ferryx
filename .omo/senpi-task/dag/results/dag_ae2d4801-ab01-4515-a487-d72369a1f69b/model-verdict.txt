### 1. Minimal Implementation Boundary & Architectural Choice

#### Core Principle: Worktree-Partitioned Layout Store with Single Unified Session Pool
- `WorkspaceState` in `ui/src/state/workspaceStore.ts` manages a dictionary of layouts keyed by worktree path: `layoutsByWorktreePath: Record<string, LayoutState>`.
- `state.layout` continuously reflects the active worktree (`state.activeWorktreePath`).
- Switching worktrees (`SELECT_WORKTREE`) writes the current active `layout` into `layoutsByWorktreePath[prevActivePath]`, sets `activeWorktreePath = nextPath`, and loads `layoutsByWorktreePath[nextPath] ?? createLayoutState()`.
- All tab-mutating actions (`ADD_TAB_WITH_SESSION`, `CLOSE_TAB`, `SPLIT_PANE`, etc.) update `state.layout` and synchronize to `layoutsByWorktreePath[activeWorktreePath]`.
- Terminal sessions across all worktrees remain stored in `state.sessions: Record<string, TerminalSession>`.
- When worktree B is active, `state.layout.tabs` contains only worktree B's terminal and browser tabs, making worktree A's tabs completely invisible in `TerminalSplitView`.
- On restart, `deserializeWorkspaceState` reconstructs `layoutsByWorktreePath` for every worktree, populates `state.sessions` across all worktrees, and activates the persisted `activeWorktreePath`.

### 2. Single Persistence API Shape

#### TypeScript DTOs (`ui/src/lib/types.ts`)
```ts
export interface PersistedTab {
  id: string;
  label: string;
  kind?: "terminal" | "browser";
  pinned?: boolean;
  worktreePath?: string;
  terminal?: PersistedTerminalTabState;
  browser?: PersistedBrowserTabState;
  customTitle?: string;
  // legacy compatibility
  sessionId?: string;
  paneTree?: PaneNode;
  sessionIdsByLeafId?: Record<string, string>;
  activeLeafId?: string | null;
  expandedLeafId?: string | null;
}

export interface PersistedLayout {
  splitMode: string;
  primaryTabId: string | null;
  secondaryTabId: string | null;
  activeTabId: string | null;
  tabs: PersistedTab[];
  tabGroups?: PersistedTabGroup[];
  tabGroupLayout?: TabGroupLayoutNode | null;
  focusedGroupId?: string | null;
  layoutsByTabId?: Record<string, TabPaneLayout>;
}

export interface PersistedWorkspace {
  workspaceId: string;
  repoRoot: string;
  worktrees: PersistedWorktree[];
  activeWorktreePath: string | null;
  /** Active worktree layout for backward compatibility */
  layout: PersistedLayout;
  /** Authoritative per-worktree layout map */
  layoutsByWorktree?: Record<string, PersistedLayout>;
  terminalSessions: Record<string, PersistedTerminalSession>;
}
```

#### Rust Schema (`src-tauri/src/session/mod.rs`)
```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct PersistedWorkspace {
    pub workspace_id: String,
    pub repo_root: PathBuf,
    pub worktrees: Vec<PersistedWorktree>,
    pub active_worktree_path: Option<String>,
    pub layout: PersistedLayout,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub layouts_by_worktree: Option<HashMap<String, PersistedLayout>>,
    pub terminal_sessions: HashMap<String, PersistedTerminalSession>,
}
```

### 3. Exact Files to Modify

1. **`ui/src/lib/types.ts`**
   - Add `worktreePath?: string` to `BrowserTab` and `PersistedTab`.
   - Add `layoutsByWorktree?: Record<string, PersistedLayout>` to `PersistedWorkspace`.
   - Add `layoutsByWorktreePath?: Record<string, LayoutState>` to `WorkspaceState`.

2. **`ui/src/state/workspaceStore.ts`**
   - Update `WorkspaceState` and `createInitialState` to track `layoutsByWorktreePath`.
   - Update `workspaceReducer` to partition layouts on `SELECT_WORKTREE`, `SET_WORKTREES`, and layout actions.
   - Update `ensureTabForWorktree` to switch worktrees and activate existing worktree-scoped tabs without cross-worktree tab collisions.
   - Update `createBrowserTab` to stamp the active worktree's path on new browser tabs.
   - Ensure session cleanup (`getDisposableSessionsForTab`, `syncWorktrees`) checks all layouts in `layoutsByWorktreePath` so inactive worktree sessions are not prematurely destroyed.

3. **`ui/src/lib/sessionPersistence.ts`**
   - In `serializeWorkspaceState`: flush active layout to `layoutsByWorktreePath`, serialize each entry into `persistedWorkspace.layoutsByWorktree`, populate `persistedWorkspace.layout` with the active worktree layout, and record sessions referenced across all worktree layouts.
   - In `deserializeWorkspaceState`: reconstruct `layoutsByWorktreePath` from `layoutsByWorktree` (or partition `layout.tabs` by `worktreePath` for legacy payloads), set `layout` to `layoutsByWorktreePath[activeWorktreePath]`, and restore all referenced sessions.

4. **`ui/src/App.tsx`**
   - Update session restore bootstrap so dead PTY respawn covers sessions across all restored worktrees.
   - Route `handleSelectTerminalTab` and `handleSelectWorktree` to smoothly transition active worktree scope.

5. **`src-tauri/src/session/mod.rs`**
   - Add `layouts_by_worktree: Option<HashMap<String, PersistedLayout>>` to `PersistedWorkspace`.
   - Update `load_session_from_path` version check to accept `session.version == 1 || session.version == 2`.

### 4. Exact RED Test Order

1. **`ui/src/lib/sessionPersistence.test.ts`**
   - **Test 1:** `round-trips multi-worktree layouts where worktree A and worktree B preserve independent terminal and browser tab sets`
     - Asserts `serializeWorkspaceState` writes distinct `layoutsByWorktree` entries for `/workspace/main` and `/workspace/feature`.
     - Asserts `deserializeWorkspaceState` reconstructs `layoutsByWorktreePath` without leaking worktree A tabs into worktree B.

2. **`ui/src/state/workspaceStore.test.tsx`**
   - **Test 2:** `isolates visible tabs per worktree and restores tab set on worktree switch`
     - Opens tabs in worktree A, switches to worktree B, opens tabs in worktree B.
     - Asserts `state.layout.tabs` contains only worktree B tabs.
     - Switches back to worktree A; asserts `state.layout.tabs` contains only worktree A tabs.
   - **Test 3:** `retains inactive worktree terminal sessions when modifying active worktree layout`
     - Verifies closing a tab or pane in worktree A does not close PTYs or delete sessions belonging to worktree B.

3. **`ui/src/App.test.tsx`**
   - **Test 4:** `renders only active worktree tabs on boot and switches visible tab list when selecting another worktree in sidebar`
     - Seeds `loadSession` with a v2 multi-worktree session.
     - Verifies only worktree A tabs render in the tab strip on startup.
     - Simulates clicking worktree B; verifies tab strip updates to display only worktree B tabs.

4. **`src-tauri/tests/session_persistence_integration.rs`**
   - **Test 5:** `test_v2_session_with_worktree_layouts_roundtrip`
     - Verifies Rust `save_session_to_path` and `load_session_from_path` persist and reload `layouts_by_worktree` with version 2 without parse errors or fallback to `.corrupted`.

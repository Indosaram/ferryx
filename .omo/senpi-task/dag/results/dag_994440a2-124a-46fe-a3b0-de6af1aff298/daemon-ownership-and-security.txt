I read this as a completed daemon-architecture delivery - the owned changes are implemented, tested, and verified with the requested commands.

Implemented daemon-only ownership and persistence contracts:

- Explicit canonical `RegisterWorkspace`; no daemon-CWD/default workspace inference.
- Spawn resolves only registered workspace/worktree identity and rejects CWD and symlink escapes.
- Secure runtime directory, lock, and socket handling with UID/type/symlink/mode validation.
- Stale sockets are removed only after acquiring the daemon lock.
- External daemon startup waits for the exact `FERRYX_DAEMON_READY` stdout event, then makes one connection attempt.
- Daemon owns persistent remote state, listener lifecycle, authentication, active selection, and the same `TerminalService` used by PTYs.
- Remote listener remains off unless explicitly enabled or restored from daemon-persisted configuration.
- Typed replay-gap frames include sequence boundaries and base64 history.
- Lag recovery replays only after the last emitted sequence, bounded by retained history.
- Concurrent duplicate spawn requests are serialized; request caching is TTL-bounded and never creates a second live shell.
- Protocol mismatch returns `ProtocolMismatch` and closes the connection without creating a PTY.
- Natural terminal exit now closes the daemon-owned output-hub stream.

### Public protocol handoff for the Tauri bridge

| Client method / operation | Request | Success response | Notes |
|---|---|---|---|
| Connection handshake | `Handshake { version }` | `HandshakeOk { version, pid, epoch }` | Mismatch returns typed `ProtocolMismatch { expectedVersion, receivedVersion }`; connection then closes. |
| Workspace registration | `RegisterWorkspace { workspaceId, repoRoot }` | `RegisterWorkspaceOk` | `repoRoot` must be an absolute, canonical Git repository root. |
| Spawn terminal | `Spawn { clientRequestId, workspaceId, worktree, cwd, cols, rows }` | `SpawnOk { sessionId }` | Workspace must already be registered. CWD must remain inside the resolved workspace/worktree root. |
| Describe terminal | `DescribeSession { sessionId }` | `DescribeSessionOk { session }` | Includes workspace/worktree identity, CWD, size, running state, and retained sequence range. |
| Attach terminal | `Attach { sessionId, afterSequence }` | `AttachOk { epoch, sessionId, startSequence, endSequence, gap, history }` | Uses a dedicated connection and base64 history. |
| Live output | N/A | `Output { sessionId, sequence, data }` | `data` is base64. |
| Lag recovery | N/A | `replayGap { sessionId, requestedAfterSequence, availableFromSequence, startSequence, endSequence, history }` | `history` is base64 and bounded by retained history. |
| Terminal exit | N/A | `Exit { sessionId, exitCode }` | Output stream closes on natural PTY exit. |
| Write | `Write { sessionId, data }` | `WriteOk` | `data` is base64. |
| Resize | `Resize { sessionId, cols, rows }` | `ResizeOk` | Operates on daemon-owned PTY. |
| Signal | `Signal { sessionId, signal }` | `SignalOk` | Operates on daemon-owned PTY. |
| Close | `Close { sessionId }` | `CloseOk` | Removes daemon session metadata and output history. |
| List sessions | `ListSessions` | `ListSessionsOk { epoch, sessions }` | Sessions are daemon-owned. |
| Remote status | `RemoteGetStatus` | `RemoteStatusOk { status }` | Status includes mode, port, control flag, running state, and bound address. |
| Remote configure | `RemoteConfigure { config }` | `RemoteConfigureOk` | `mode: off` stops the listener; enabled modes bind through the daemon. |
| Pairing code | `RemoteCreatePairingCode { permission }` | `RemotePairingCodeOk { code }` | Default permission is control when omitted. |
| Device list | `RemoteListDevices` | `RemoteListDevicesOk { devices }` | Reads daemon-owned authentication state. |
| Device revoke | `RemoteRevokeDevice { deviceId }` | `RemoteRevokeDeviceOk` | Unknown/already-revoked device returns `Error`. |
| Set active selection | `RemoteSetActiveSelection { selection }` | `RemoteSetActiveSelectionOk` | Selection contains safe workspace/worktree/session identifiers. |
| Get active selection | `RemoteGetActiveSelection` | `RemoteGetActiveSelectionOk { selection }` | Remote terminal exposure follows this daemon-owned selection. |
| General failure | Any | `Error { message }` | Operational/validation errors; protocol mismatch uses the dedicated typed response. |

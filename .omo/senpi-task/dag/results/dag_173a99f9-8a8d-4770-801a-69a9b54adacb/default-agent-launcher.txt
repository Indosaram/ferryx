Default Agent now changes the New Tab launcher instead of being a dead Settings preference.

When `defaultAgentId` is enabled and available, that agent is first in the New Tab list with a visible, accessible `Default` label. Click still launches the exact clicked agent object. Missing, `none`, disabled, or unavailable defaults keep natural order and show no badge. Settings copy describes this and does not claim auto-launch.

`defaultAgentId` is wired `App` → `TerminalSplitView` → `TabBar` → `NewTabPopover`.

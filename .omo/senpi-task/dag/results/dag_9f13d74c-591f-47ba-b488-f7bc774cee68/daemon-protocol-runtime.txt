### 2. Implementation Summary

1. **Explicit Workspace Registration & No CWD Inference**:
   - Added `DaemonRequest::RegisterWorkspace { workspace_id, repo_root }` and `DaemonResponse::RegisterWorkspaceOk`.
   - Removed inference of workspace from `current_dir()`. Spawning requires prior workspace registration or returns an explicit error.
   - Enforced canonicalization and directory checks via `WorkspaceRegistry::register`.

2. **Filesystem Ownership & Symlink Hardening**:
   - `get_runtime_dir()` and `run_server()` inspect `symlink_metadata` to prohibit symlinks and foreign UID ownership on runtime directories, lock files, and Unix domain sockets.
   - Lock file acquired with non-blocking exclusive `flock`; stale socket file removed only after holding lock and verifying safe ownership. Permissions enforced at `0o700` (directory) and `0o600` (socket).

3. **Event-Driven Bounded Readiness Path**:
   - Replaced `connect_or_spawn` polling sleep loop with an exact readiness signal reader awaiting `FERRYX_DAEMON_READY` with a 5-second bounded timeout, immediately connecting upon receipt without sleep delays.

4. **Daemon-Owned Remote Gateway Lifecycle**:
   - Network listener is disabled by default (`RemoteNetworkMode::Off`).
   - Daemon manages `RemoteGatewayState` and active listener lifecycle binding the daemon's `TerminalService`.
   - Added typed control commands: `RemoteGetStatus`, `RemoteConfigure`, `RemoteCreatePairingCode`, `RemoteListDevices`, `RemoteRevokeDevice`, `RemoteSetActiveSelection`, `RemoteGetActiveSelection`.

5. **Typed Replay-Gap Broadcast Recovery**:
   - Updated `DaemonStreamMessage::Lagged` to carry `gap: Option<ReplayGap>` (requested vs available sequence bounds) alongside `start_sequence`, `end_sequence`, and base64-encoded `history`.
   - `pump_sequenced_stream` tracks `last_seen_sequence` to resubscribe after sequence gap and pump replay snapshots.

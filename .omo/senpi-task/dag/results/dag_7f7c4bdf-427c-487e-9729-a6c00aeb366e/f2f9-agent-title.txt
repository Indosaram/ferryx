### Summary of Fixes for Defects F2 and F9

- **F2 (Prefix-limited Agent Detection)**: Removed global mid-string regex testing (`agent.pattern.test(lower)`) which falsely matched agent keywords anywhere in the terminal title (e.g. `'git commit -m "fix cursor position"'`). Restructured detection to match strictly on the leading prefix / token of `withoutSpinner` using `taskPattern.exec(withoutSpinner)`. Mid-string matches are now correctly rejected as non-agents while genuine leading agent titles remain detected.
- **F9 (Honest Non-agent State)**: Changed the non-agent fallback state from unconditionally hardcoded `'working'` to dynamically derived via `resolveParsedAgentState(normalized)`. When no activity or spinner signal is present, non-agent processes receive the neutral starting/idle state (`'starting'`), avoiding false active status dot indicators.

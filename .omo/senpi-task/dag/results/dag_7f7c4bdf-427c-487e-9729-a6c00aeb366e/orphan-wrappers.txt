### Intent & Deliverable Summary
Connected all seven orphaned IPC wrappers (`listRemoteDevices`, `revokeRemoteDevice`, `getTailscaleStatus`, `setBrowserZoom`, `focusBrowser`, `getBrowserState`, `listBrowsers`) to frontend UI components and added test coverage.

---

### Wrapper UI Wiring

| Wrapper | UI Surface | Interaction / Behavior |
|---|---|---|
| `listRemoteDevices` | `SettingsDialog.tsx` (`RemoteAccessSettings`) | Queries and renders paired remote devices (name, permissions, last seen timestamp, revocation status) on load, gateway toggle, and revocation. |
| `revokeRemoteDevice` | `SettingsDialog.tsx` (`RemoteAccessSettings`) | Per-device Revoke button with inline confirmation step ("Confirm Revoke" / "Cancel") calling `revokeRemoteDevice(deviceId)`. |
| `getTailscaleStatus` | `SettingsDialog.tsx` (`RemoteAccessSettings`) | Displays live Tailscale status line (Running with tailnet name, Disconnected, or Not Installed, along with Self-DNS). |
| `setBrowserZoom` | `SettingsDialog.tsx` (`BrowserSettings`) & `BrowserToolbar.tsx` | Invoked on changing default zoom level in Browser Settings across active browsers, and via Zoom In / Zoom Out toolbar buttons in `BrowserToolbar`. |
| `focusBrowser` | `SettingsDialog.tsx` (`BrowserSettings`) & `BrowserToolbar.tsx` | Focus button per active browser session in Settings and "Focus webview" target button in `BrowserToolbar`. |
| `getBrowserState` | `BrowserToolbar.tsx` | "Sync browser state" button on `BrowserToolbar` querying live webview state and syncing current URL. |
| `listBrowsers` | `SettingsDialog.tsx` (`BrowserSettings`) | Lists active browser sessions in Browser Settings and discovers active webviews to apply zoom updates. |

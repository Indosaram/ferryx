All structs need `#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]` with `#[serde(rename_all = "camelCase")]`:

    pub version: u32,
    pub timestamp: u64,
    pub active_workspace_id: String,
    pub workspaces: HashMap<String, PersistedWorkspace>,

### 2. Storage Helpers & Atomic Write Strategy
- **Functions**:
  - `save_session_to_path(path: &Path, session: &PersistedWorkspaceSession) -> Result<(), SessionError>`
  - `load_session_from_path(path: &Path) -> Result<Option<PersistedWorkspaceSession>, SessionError>`
  - `clear_session_from_path(path: &Path) -> Result<(), SessionError>`
- **Atomic Save**:
  1. Ensure parent directories exist.
  2. Write to a temporary file (`<path>.tmp.<pid>.<uuid>`).
  3. Flush/sync to disk.
  4. If target `<path>` exists, copy/rename to `<path>.backup`.
  5. Atomically rename the temporary file to `<path>`.
- **Corrupted File Fallback**:
  - In `load_session_from_path`, if `<path>` exists but fails to parse as valid JSON, attempt reading `<path>.backup`. If both are missing, return `Ok(None)`.
- **Clear**:
  - Remove `<path>` and `<path>.backup` (and any leftover `.tmp` if present). Missing files should not error (`NotFound` ignored).

### 3. Tauri IPC Commands (`src-tauri/src/ipc/session.rs`)
- Resolve default storage file via `app.path().app_data_dir().map(|dir| dir.join("session_state.json"))`.
- `cmd_session_save<R: Runtime>(app: AppHandle<R>, state: PersistedWorkspaceSession) -> Result<(), IpcError>`
- `cmd_session_load<R: Runtime>(app: AppHandle<R>) -> Result<Option<PersistedWorkspaceSession>, IpcError>`
- `cmd_session_clear<R: Runtime>(app: AppHandle<R>) -> Result<(), IpcError>`

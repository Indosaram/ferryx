## Policy

Enabling a listener is **process-scoped**. A new `RemoteGatewayState` never restores or auto-starts a network listener. Port / `allowControl` and paired devices still persist.

## Source behavior

`src-tauri/src/remote/state.rs`
- Added `RemoteRestartPolicy::SessionOnly` (`config.restart_policy()`).
- `persist_config()` writes `mode: off` plus `restartPolicy: sessionOnly`. Live in-memory mode can stay `localNetwork` while the process is enabled.
- `new_with_paths` still loads port/`allowControl`, then forces `mode = Off`, `is_running = false`. Stale `localNetwork` files cannot look enabled.

`src-tauri/src/ipc/remote.rs`
- Status: `enabled` is only `is_running`; after relaunch `mode` is `off`; `restartPolicy` is `sessionOnly`.
- Enable/disable persist the session-only snapshot (no-op when there is no config path).

Auth persistence is unchanged (`remote-auth.json`).

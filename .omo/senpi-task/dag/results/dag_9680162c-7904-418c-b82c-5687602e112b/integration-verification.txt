### 2. Source Inspection & Wire Contract Validation

1. **Rust Bounded Output Hub**:
   - Remote WebSocket streaming via `/api/v1/terminal/{sessionId}` attaches to `TerminalService::attach` (`src-tauri/src/terminal/service.rs`), which subscribes to the bounded output hub (`TerminalOutputHub` in `src-tauri/src/terminal/output_hub.rs`).
   - Replay backlog on attach sends the buffer snapshot, followed by live chunks received over the broadcast channel.
2. **Mobile Wire Contract Preservation**:
   - `ClientControlMessage` (`Resize`, `Signal`, `Ping`) and `ServerControlMessage` (`Pong`, `Error`) in `src-tauri/src/remote/protocol.rs` remain intact.
   - Remote terminal client (`ui/src/remote/RemoteTerminal.tsx`) continues to send binary stdin and json control messages (`resize`, `signal`) without contract drift.
3. **Frontend Scaling Implementation**:
   - `ui/src/lib/terminalHostManager.ts` enforces `DEFAULT_WARM_CACHE_LIMIT = 2` for inactive terminal instances, evicting the oldest unmounted renderer instances to avoid memory leaks while retaining warm instances for fast switching.
   - Unmounted/inactive renderers unsubscribe from output streams, while background OSC title tracking (`ui/src/lib/terminalEvents.ts`) continues to update tab activity.

### 3. Corrective Edits Made

- **File**: `ui/src/test/setup.ts`
- **Correction**: Changed `clearHmrWorkspaceState` import path from `../state/workspaceStore` to `../state/hmrWorkspaceState`.
- **Reason**: Eager top-level import of `workspaceStore` during test setup initialized the Tauri IPC bridge module before individual test file mocks were applied, causing test pollution across mock-dependent test suites. Importing directly from pure `hmrWorkspaceState` eliminates this side-effect.

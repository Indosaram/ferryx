### 1. Executive Implementation Boundary & Ownership Lanes

To scale Ferryx reliably to 5 workspaces with 20+ terminals each without WebGL context exhaustion, UI main-thread event starvation, or navigation lag, the implementation boundaries must strictly separate **Renderer Lifecycle**, **Output Scheduling**, and **Workspace Navigation**.

| Lane | Domain | File Ownership (Write Scope) | Parallelism Constraint | Shared Seam / Dependency |
|---|---|---|---|---|
| **Lane 1: Output Scheduling** | Frame batching, write coalescing, replay ordering | `ui/src/lib/terminalHostManager.ts` (write queue), `ui/src/lib/terminalHostManager.test.ts` | **SERIALIZED with Lane 2** | Touches instance write binding in `terminalHostManager.ts`. Must precede lifecycle LRU to ensure eviction flushes pending rAF queues cleanly. |
| **Lane 2: Renderer Lifecycle** | Visible tracking, LRU warm cache, WebGL context bounding | `ui/src/lib/terminalHostManager.ts` (LRU/visible state), `ui/src/components/TerminalPane.tsx` (mount hooks), `ui/src/lib/terminalHostManager.test.ts` | **SERIALIZED after Lane 1** | Modifies `terminalHostManager.ts` and `TerminalPane.tsx`. Reuses the output queue from Lane 1. |
| **Lane 3: Workspace Navigation** | Parked-layout state transitions, 0-PTY-spawn fast path | `ui/src/state/workspaceStore.ts`, `ui/src/state/workspaceStore.test.tsx` | **INDEPENDENT / PARALLEL with Lanes 1 & 2** | Pure in-memory reducer operations (`worktreeLayouts`). Completely disjoint from `terminalHostManager.ts`. |
| **Lane 4: Verification Gate** | Full test suite, UI compilation, and native contract checks | Read-only verification runner across all modified targets | **FINAL CONVERGENCE (Depends on Lanes 1, 2, 3)** | Gates release readiness. |

### 2. File:Line Source Evidence Independently Checked

#### A. Shared `terminalHostManager.ts` Bottleneck & Serial Requirement
* **Synchronous Unbatched Output Binding**: `ui/src/lib/terminalHostManager.ts:133-138` and `172-177`. Output subscriptions invoke `terminal.write(text)` synchronously on every incoming decoded chunk, causing main-thread parser lock during high-throughput agent streaming.
* **Lack of LRU Eviction**: `ui/src/lib/terminalHostManager.ts:28-66`. `instances` retains every instantiated `TerminalInstance` in a `Map<string, TerminalInstance>` until explicit tab closure (`destroy()` at lines `236-247`). Inactive tabs retain WebGL contexts (`attachWebglRenderer` at lines `100-104`), exceeding browser context caps (>8–16).
* **Pane Detach Without Host Disposal**: `ui/src/components/TerminalPane.tsx:30-64`. React unmount only sets `cancelled = true` (`TerminalPane.tsx:61-63`), retaining background renderers indefinitely.
* **Conclusion**: Both **Output Scheduling** (rAF write queue) and **Renderer Lifecycle** (LRU eviction / visible tracking) mutate `TerminalInstance` and `TerminalHostManager` in `ui/src/lib/terminalHostManager.ts`. **They must be serialized into ordered implementation steps to avoid code overwrite and race hazards.**

#### B. Independent Workspace Navigation Seam
* **Parked Layout Preservation**: `ui/src/state/workspaceStore.ts:860-864` (`SELECT_WORKTREE`) saves inactive layouts in `state.worktreeLayouts[worktreePath]`.
* **Zero-Spawn Navigation**: `ui/src/state/workspaceStore.ts:222-234` (`ensureTabForWorktree`) synchronously restores parked layouts and dispatches `SELECT_WORKTREE` and `ACTIVATE_TAB` without invoking `services.spawnTerminal(...)` (`workspaceStore.ts:173-195`) or `services.waitForTerminalExit(...)` (`workspaceStore.ts:472-488`).
* **Direct Tab Switching**: `ui/src/state/workspaceStore.ts:1067-1088` (`ACTIVATE_TAB`) switches across parked worktrees in memory.
* **Conclusion**: Navigation strictly touches `LayoutState` and `worktreeLayouts` in `workspaceStore.ts`; it does not touch `terminalHostManager.ts` or native PTY sessions.

#### C. Backlog & Replay Continuity
* **Frontend Backlog**: `ui/src/lib/terminalEvents.ts:5`, `14-17`, `153-176`. Retains up to 512 KiB per session and scans OSC titles across chunks (`ui/src/lib/terminalEvents.ts:29-53`) regardless of renderer mount state.
* **Rust Native Backlog**: `src-tauri/src/terminal/output_hub.rs:8-39`, `60-70`. `BoundedBuffer` retains up to 512 KiB in `VecDeque<Vec<u8>>` for reconnecting remotes and reattaching renderers.

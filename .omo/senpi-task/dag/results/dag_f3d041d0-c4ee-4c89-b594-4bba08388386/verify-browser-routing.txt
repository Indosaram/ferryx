### Browser Pane-Edge Routing Verification Report

#### 1. Code and Test Inspection Findings

1. **Browser Drag to Terminal Pane Edge Routes to Group Split (No `targetPane`)**
   - **Source:** `ui/src/components/TerminalSplitView.tsx` (lines 266–284 in `case "move-tab-to-pane-split"`):
     ```typescript
     const sourceTab = normalizedLayout.tabs.find((candidate) => candidate.id === command.sourceTabId);
     if (sourceTab?.kind === "browser") {
       onMoveTabToSplit?.(
         command.sourceTabId,
         targetGroupId,
         command.direction,
         command.position,
       );
       return Boolean(onMoveTabToSplit);
     }
     ```
     When `sourceTab.kind === "browser"`, `TerminalSplitView` intentionally invokes `onMoveTabToSplit` with 4 parameters (`sourceTabId`, `targetGroupId`, `direction`, `position`), omitting `targetPane`.
   - **Component Test Proof:** `ui/src/components/TerminalSplitView.browserPaneDrop.runtime.test.tsx`
     Dragging an inactive browser tab onto a terminal pane edge (`pane-edge` on `leaf-target`) calls `onMoveTabToSplit("browser-source", "group-default", "horizontal", "second")` without `targetPane`.

2. **State Gains the Correct Adjacent Group**
   - **Source:** `ui/src/state/workspaceStore.ts` and `ui/src/state/layout.ts`:
     When `onMoveTabToSplit` is called without `targetPane`, `workspaceStore` dispatches `{ type: "MOVE_TAB_TO_SPLIT", sourceTabId, targetGroupId, direction, position }`. The layout reducer creates a new `TabGroup` containing `[sourceTabId]` and nests it in `tabGroupLayout` adjacent to `targetGroupId` under a split node.
   - **Store Test Proof:** `ui/src/state/workspaceStore.browserPaneDrop.runtime.test.tsx`
     - `targetGroup.tabIds` is `["terminal-target"]`.
     - `sourceGroup.tabIds` is `["browser-source"]`.
     - `tabGroupLayout` is `{ type: "split", direction: "horizontal", first: { type: "group", groupId: targetGroup.id }, second: { type: "group", groupId: sourceGroup.id } }`.

3. **Browser Appears Exactly Once with Metadata**
   - **Store Test Proof:** `ui/src/state/workspaceStore.browserPaneDrop.runtime.test.tsx`
     `state.layout.tabs.filter(tab => tab.id === "browser-source")` has `length: 1` and preserves all `BrowserTab` properties (`browserId: "browser-1"`, `url: "https://example.com"`, `label: "Browser Source"`, `kind: "browser"`).

4. **Terminal Pane Tree is Unchanged**
   - **Source:** `ui/src/state/tabPaneDrop.ts` guards `if (sourceTab.kind === "browser" || targetTab.kind === "browser") return state;`. Because `TerminalSplitView` executes group split directly, `moveTabIntoPaneSplit` is bypassed entirely.
   - **Store Test Proof:** `ui/src/state/workspaceStore.browserPaneDrop.runtime.test.tsx`

### Implementation Summary

1. **Active Desktop Selection State (`src-tauri/src/remote/protocol.rs`, `src-tauri/src/remote/state.rs`)**
   - Added in-memory `RemoteActiveDesktopSelection` on `RemoteGatewayState` storing safe identifiers only: `workspace_id`, `worktree_slug`, `worktree_label`, and `session_id` — strictly excluding local absolute paths, repo roots, and cwd.
   - Added `DesktopEventSink` hook on `RemoteGatewayState` to bridge events to the Tauri runtime.

2. **Desktop Selection IPC Commands (`src-tauri/src/ipc/remote.rs`, `src-tauri/src/lib.rs`)**
   - Added typed IPC commands `cmd_remote_set_active_selection` and `cmd_remote_get_active_selection` to set and retrieve active selection from desktop UI.
   - Configured `remote_state.set_desktop_event_sink` in Tauri's app setup to broadcast desktop events to the window.
   - Registered commands in `tauri::generate_handler!`.

3. **Background Session Exclusion & Active-Only Authorization (`src-tauri/src/remote/server.rs`)**
   - `GET /api/v1/sessions` and `GET /api/v1/workspace/state` now filter sessions strictly through `get_active_running_sessions`, exposing at most the declared active, running session.
   - `/api/v1/terminal/:sessionId` validates `session_id` against the active desktop selection; any other session is rejected immediately with `403 Forbidden` even if its PTY exists.

4. **Safe Control-Only Mobile Selection Bridge (`src-tauri/src/remote/server.rs`)**
   - Added `POST /api/v1/workspace/select` and `POST /api/v1/workspace/selection`.
   - Validates device token and rejects View-only permissions with `403 Forbidden`.
   - Validates workspace ID and worktree identity against `WorkspaceRegistry` (rejecting unregistered targets with `400 Bad Request`).
   - Emits Tauri desktop event `remote_selection_requested` (`REMOTE_SELECTION_REQUEST_EVENT`) carrying safe IDs/slug without absolute paths or repo roots.

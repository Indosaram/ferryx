### 2. Standalone Daemon + PTY Reconnect Harness Scenario (No Fixed Sleeps)

This scenario proves child PID persistence across client disconnect/reconnect cycles without GUI automation or arbitrary fixed sleeps.

#### Execution Architecture

```text
[ Test Driver ] ──1. Start Daemon (Isolated Temp Dir & Socket) ────────────────► [ Daemon Server ]
[ Test Driver ] ──2. Connect Client A (Await UDS Ready via Poll/Backoff) ──────► [ Daemon Server ]
[ Test Driver ] ──3. Spawn PTY Shell (/bin/sh -c 'echo PID:$$; exec cat') ───► [ Spawn Shell (PID X) ]
[ Test Driver ] ◄─4. Stream Output: Read Sentinel 'PID:<pid>' (Bounded Timeout) ─┘
[ Test Driver ] ──5. Disconnect Client A (Drop UDS Connection)
[ Test Driver ] ──6. Assert Shell PID X alive (via libc::kill(PID, 0) == 0)
[ Test Driver ] ──7. Connect Client B (Await UDS Connection) ──────────────────► [ Daemon Server ]
[ Test Driver ] ──8. Attach to Session (Session ID from step 3) ──────────────► [ Replay + Stream ]
[ Test Driver ] ──9. Write 'echo ping_reconnect\n' over Client B
[ Test Driver ] ◄─10. Receive 'ping_reconnect' from Shell PID X (Bounded Timeout)
[ Test Driver ] ──11. Send Close(session_id) ──────────────────────────────────► [ Daemon Server ]
[ Test Driver ] ──12. Await Process Exit (Bounded Timeout on waitpid/kill(PID,0))
```

#### Deterministic Harness Specification (Rust `tokio::test` Pattern)

```rust
// Proposed harness integration: src-tauri/tests/daemon_pty_reconnect_harness.rs
use std::time::Duration;
use tokio::time::timeout;
use tokio::net::UnixStream;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};

#[tokio::test]
async fn test_daemon_pty_session_persists_across_client_reconnect_without_sleeps() {
    let temp_dir = tempfile::tempdir().expect("tempdir");
    let socket_path = temp_dir.path().join("daemon.sock");
    
    // 1. Start isolated daemon server bound to socket_path
    let server = ferryx_lib::daemon::server::DaemonServer::new_at_path(&socket_path);
    let server_handle = tokio::spawn(async move {
        server.run_server().await
    });

    // 2. Poll socket connection with bounded timeout (NO fixed sleep)
    let stream_a = timeout(Duration::from_secs(3), async {
        loop {
            if let Ok(stream) = UnixStream::connect(&socket_path).await {
                break stream;
            }
            tokio::task::yield_now().await;
        }
    }).await.expect("Daemon socket readiness timeout");

    // 3. Handshake & Spawn terminal shell with sentinel
    let (read_a, mut write_a) = stream_a.into_split();
    let mut reader_a = BufReader::new(read_a);
    
    // Send Handshake
    write_a.write_all(b"{\"Handshake\":{\"version\":1}}\n").await.unwrap();
    let mut line = String::new();
    reader_a.read_line(&mut line).await.unwrap();
    assert!(line.contains("HandshakeOk"));

    // Spawn /bin/sh that outputs its own PID
    write_a.write_all(
        b"{\"Spawn\":{\"workspaceId\":\"test-ws\",\"command\":\"sh\",\"args\":[\"-c\",\"echo PID_SENTINEL:$$ && exec cat\"]}}\n"
    ).await.unwrap();
    
    // 4. Capture Session ID and Child PID via bounded token matching
    let (session_id, child_pid) = timeout(Duration::from_secs(5), async {
        let mut line = String::new();
        let mut captured_sid = None;
        let mut captured_pid = None;
        while captured_sid.is_none() || captured_pid.is_none() {
            line.clear();
            reader_a.read_line(&mut line).await.unwrap();
            if line.contains("Spawned") {
                // Parse session_id
                captured_sid = Some(parse_session_id(&line));
            }
            if let Some(pos) = line.find("PID_SENTINEL:") {
                let pid_str = line[pos + 13..].trim();
                captured_pid = Some(pid_str.parse::<i32>().unwrap());
            }
        }
        (captured_sid.unwrap(), captured_pid.unwrap())
    }).await.expect("Spawn and PID output timeout");

    // 5. Disconnect Client A (Simulate GUI process termination / SIGKILL)
    drop(write_a);
    drop(reader_a);

    // 6. Non-blocking PID survival verification
    assert_eq!(unsafe { libc::kill(child_pid, 0) }, 0, "Child shell PID must stay alive after client disconnect");

    // 7. Connect Client B to same socket
    let stream_b = UnixStream::connect(&socket_path).await.unwrap();
    let (read_b, mut write_b) = stream_b.into_split();
    let mut reader_b = BufReader::new(read_b);

    // 8. Attach to existing session ID
    let attach_cmd = format!("{{\"Attach\":{{\"sessionId\":\"{}\"}}}}\n", session_id);
    write_b.write_all(attach_cmd.as_bytes()).await.unwrap();

    // 9. Write input through reconnect stream
    write_b.write_all(b"{\"Write\":{\"sessionId\":\"" + session_id.as_bytes() + b"\",\"data\":\"RECONNECT_VERIFIED\\n\"}}\n").await.unwrap();

    // 10. Await live output reflection bounded by timeout
    timeout(Duration::from_secs(5), async {
        let mut line = String::new();
        loop {
            line.clear();
            reader_b.read_line(&mut line).await.unwrap();
            if line.contains("RECONNECT_VERIFIED") {
                break;
            }
        }
    }).await.expect("Echo output over reconnected session timeout");

    // 11. Explicit Session Close
    let close_cmd = format!("{{\"Close\":{{\"sessionId\":\"{}\"}}}}\n", session_id);
    write_b.write_all(close_cmd.as_bytes()).await.unwrap();

    // 12. Bounded wait for process exit (Verify no zombie / orphan)
    timeout(Duration::from_secs(5), async {
        loop {
            if unsafe { libc::kill(child_pid, 0) } != 0 {
                break;
            }
            tokio::task::yield_now().await;
        }
    }).await.expect("Child process cleanup timeout");

    // Stop daemon server
    server_handle.abort();
}
```

### 3. Cleanup & Resource Hygiene

To prevent stale Unix domain sockets, orphan child shells, or uncollected worktrees during local or CI runs:

| Resource | Automated Cleanup Strategy | Manual Fallback Command |
| :--- | :--- | :--- |
| **UDS Sockets & Locks** | Run inside isolated `tempfile::tempdir()` auto-dropped at test completion. | `rm -f /tmp/rorca-$(id -u)/daemon.sock /tmp/rorca-$(id -u)/daemon.lock` |
| **Orphan Test PTY Shells** | Explicit `cmd_terminal_close` / `Close` request, followed by bounded `libc::kill(pid, SIGTERM)` check in teardown. | `pkill -f "PID_SENTINEL\|wt_agent_task"` |
| **Ephemeral Test Worktrees** | Automated cleanup through `TempDir` RAII drops and git worktree prune. | `git worktree prune` |
| **Vite Cache / Build Artifacts** | Standard repo-level clean commands. | `rm -rf ui/dist target/tmp` |

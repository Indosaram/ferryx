## 1. Current Architecture & Control-Flow Analysis

### 1.1 `PtyManager` & Session Lifecycle
- **Source:** [`src-tauri/src/terminal/pty.rs:16-20`](src-tauri/src/terminal/pty.rs) and [`src-tauri/src/terminal/session.rs:39-88`](src-tauri/src/terminal/session.rs)
- **Spawn Path:** 
  - `PtyManager::spawn_with_id_and_worktree` ([`pty.rs:63-125`](src-tauri/src/terminal/pty.rs)) opens a PTY master/slave pair, spawns the child process, clones the master reader/writer, and allocates an `mpsc::channel::<Vec<u8>>(1024)` ([`pty.rs:106`](src-tauri/src/terminal/pty.rs)).
  - `PtySession::new` ([`session.rs:53-88`](src-tauri/src/terminal/session.rs)) starts a blocking background reader thread in chunks of 4096 bytes, pushing into `reader_tx` (`mpsc::Sender<Vec<u8>>`).
  - `PtyManager::start_lifecycle_watcher` ([`pty.rs:127-192`](src-tauri/src/terminal/pty.rs)) spawns a task polling process status every `LIFECYCLE_POLL_INTERVAL` (250ms, [`pty.rs:13`](src-tauri/src/terminal/pty.rs)).
- **Exit & Cleanup:**
  - When the child exits naturally ([`pty.rs:146-149`](src-tauri/src/terminal/pty.rs)), `finalize_natural_exit` ([`pty.rs:194-206`](src-tauri/src/terminal/pty.rs)) joins the reader with a 2s timeout ([`pty.rs:208-223`](src-tauri/src/terminal/pty.rs)), records `PtySessionState::Exited { code }`, closes channels, and removes the session from the manager registry ([`pty.rs:205`](src-tauri/src/terminal/pty.rs)).
  - If the PTY receiver is dropped before the process finishes (`session.output_receiver_closed()`, [`pty.rs:150-159`](src-tauri/src/terminal/pty.rs)), the lifecycle watcher initiates auto-cleanup via `close_session`.

### 1.2 `TerminalOutputHub`
- **Source:** [`src-tauri/src/terminal/output_hub.rs:10-101`](src-tauri/src/terminal/output_hub.rs)
- **Data Model:**
  - `BoundedBuffer` ([`output_hub.rs:10-43`](src-tauri/src/terminal/output_hub.rs)) stores raw byte chunks in `VecDeque<Vec<u8>>` up to `DEFAULT_BUFFER_CAPACITY = 512 KiB` ([`output_hub.rs:6`](src-tauri/src/terminal/output_hub.rs)).
  - `SessionHub` ([`output_hub.rs:45-48`](src-tauri/src/terminal/output_hub.rs)) pairs `BoundedBuffer` with `broadcast::Sender<Vec<u8>>` (`BROADCAST_CAPACITY = 1024`, [`output_hub.rs:7`](src-tauri/src/terminal/output_hub.rs)).
- **Attach Race Condition in Current Code:**
  - In `subscribe` ([`output_hub.rs:92-101`](src-tauri/src/terminal/output_hub.rs)):
    ```rust
    let hub = session_hub.read();
    let history = hub.buffer.snapshot();
    let rx = hub.sender.subscribe();
    Some((history, rx))
    ```
    Taking `snapshot()` and *then* calling `subscribe()` creates an uncoordinated sequence boundary. If `publish` occurs or if the broadcast buffer has pending chunks, the client has no monotonic sequence index to distinguish where `history` ended and `rx` live output begins, leading to missed or duplicated bytes.

### 1.3 `TerminalService`
- **Source:** [`src-tauri/src/terminal/service.rs:10-95`](src-tauri/src/terminal/service.rs)
- **Bridging:**
  - `spawn_in_worktree` ([`service.rs:36-58`](src-tauri/src/terminal/service.rs)) creates the PTY session, registers the output hub channel, and spawns a bridge loop forwarding raw `pty_rx.recv()` chunks to `output_hub.publish(...)` ([`service.rs:50-54`](src-tauri/src/terminal/service.rs)).
  - `attach` ([`service.rs:60-72`](src-tauri/src/terminal/service.rs)) verifies session existence in `pty_manager` and delegates to `output_hub.subscribe(session_id)`.
  - `close_session` ([`service.rs:86-89`](src-tauri/src/terminal/service.rs)) removes the session from `output_hub` and closes it in `pty_manager`.

### 1.4 Daemon Stream & Protocol Behavior
- **Source:** [`src-tauri/src/daemon/protocol.rs:36-112`](src-tauri/src/daemon/protocol.rs) and [`src-tauri/src/daemon/server.rs:207-226, 274-325`](src-tauri/src/daemon/server.rs)
- **Current Stream Protocol:**
  - `DaemonRequest::Attach { session_id }` ([`protocol.rs:57-59`](src-tauri/src/daemon/protocol.rs)) returns `DaemonResponse::AttachOk { history }` ([`protocol.rs:87-90`](src-tauri/src/daemon/protocol.rs)).
  - `DaemonServer::handle_client` ([`server.rs:207-226`](src-tauri/src/daemon/server.rs)) sends `AttachOk` and immediately turns the UDS connection into a dedicated stream pump via `Self::pump_stream` ([`server.rs:274-325`](src-tauri/src/daemon/server.rs)), emitting `DaemonStreamMessage::Output`, `DaemonStreamMessage::Lagged`, or `DaemonStreamMessage::Exit`.
  - **Defect:** `Attach` occupies the entire connection; `Output` lacks chunk sequence numbers; and `Lagged` sends a raw unsequenced history buffer without gap indicators or start/end sequence numbers.

## 2. Minimal Required API & Data-Model Changes

### 2.1 Monotonic Sequence & Bounded Chunk Ring (`src-tauri/src/terminal/output_hub.rs`)

Replace raw byte snapshotting with sequenced chunks and bounded window tracking:

```rust
// In src-tauri/src/terminal/output_hub.rs

#[derive(Clone, Debug, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub struct OutputChunk {
    pub sequence: u64,
    pub bytes: Vec<u8>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct AttachmentSnapshot {
    pub start_sequence: u64,
    pub end_sequence: u64,
    pub bytes: Vec<u8>,
}

#[derive(Debug, PartialEq, Eq)]
pub enum ReplayResult {
    /// Full or partial snapshot up to end_sequence
    Snapshot(AttachmentSnapshot),
    /// after_sequence is past ring capacity (overflow gap detected)
    Gap {
        requested_after_sequence: u64,
        available_from_sequence: u64,
        snapshot: AttachmentSnapshot,
    },
    /// after_sequence is already at or ahead of latest output (no history needed)
    UpToDate {
        current_sequence: u64,
    },
}

pub struct BoundedBuffer {
    capacity: usize,
    chunks: VecDeque<OutputChunk>,
    current_size: usize,
    next_sequence: u64,
    first_available_sequence: u64,
}

impl BoundedBuffer {
    pub fn new(capacity: usize) -> Self {
        Self {
            capacity,
            chunks: VecDeque::new(),
            current_size: 0,
            next_sequence: 1,
            first_available_sequence: 1,
        }
    }

    pub fn push(&mut self, data: Vec<u8>) -> OutputChunk {
        let sequence = self.next_sequence;
        self.next_sequence += 1;

        let chunk = OutputChunk { sequence, bytes: data };
        self.current_size += chunk.bytes.len();
        self.chunks.push_back(chunk.clone());

        while self.current_size > self.capacity && self.chunks.len() > 1 {
            if let Some(front) = self.chunks.pop_front() {
                self.current_size -= front.bytes.len();
                if let Some(new_front) = self.chunks.front() {
                    self.first_available_sequence = new_front.sequence;
                }
            }
        }
        chunk
    }

    pub fn replay(&self, after_sequence: Option<u64>) -> ReplayResult {
        let latest_seq = self.next_sequence.saturating_sub(1);
        if let Some(req_seq) = after_sequence {
            if req_seq >= latest_seq && latest_seq > 0 {
                return ReplayResult::UpToDate { current_sequence: latest_seq };
            }
            if req_seq < self.first_available_sequence.saturating_sub(1) {
                return ReplayResult::Gap {
                    requested_after_sequence: req_seq,
                    available_from_sequence: self.first_available_sequence,
                    snapshot: self.build_snapshot_from(self.first_available_sequence),
                };
            }
            return ReplayResult::Snapshot(self.build_snapshot_from(req_seq + 1));
        }
        ReplayResult::Snapshot(self.build_snapshot_from(self.first_available_sequence))
    }

    fn build_snapshot_from(&self, from_sequence: u64) -> AttachmentSnapshot {
        let mut bytes = Vec::new();
        let mut start_seq = 0;
        let mut end_seq = 0;

        for chunk in &self.chunks {
            if chunk.sequence >= from_sequence {
                if start_seq == 0 {
                    start_seq = chunk.sequence;
                }
                end_seq = chunk.sequence;
                bytes.extend_from_slice(&chunk.bytes);
            }
        }
        AttachmentSnapshot {
            start_sequence: start_seq,
            end_sequence: end_seq,
            bytes,
        }
    }
}
```

### 2.2 Subscriber-Before-Snapshot Atomic Attach (`output_hub.rs` & `service.rs`)

Ensure `broadcast::Receiver` is created inside the same lock window before the snapshot is evaluated:

```rust
// In src-tauri/src/terminal/output_hub.rs

struct SessionHub {
    buffer: BoundedBuffer,
    sender: broadcast::Sender<OutputChunk>,
}

impl TerminalOutputHub {
    pub fn subscribe(
        &self,
        session_id: &str,
        after_sequence: Option<u64>,
    ) -> Option<(ReplayResult, broadcast::Receiver<OutputChunk>)> {
        let sessions = self.sessions.read();
        let session_hub = sessions.get(session_id)?.clone();
        drop(sessions);

        let hub = session_hub.read();
        // 1. Subscribe to broadcast FIRST
        let rx = hub.sender.subscribe();
        // 2. Snapshot replay state in the same critical section
        let replay = hub.buffer.replay(after_sequence);
        Some((replay, rx))
    }

    pub fn publish(&self, session_id: &str, data: Vec<u8>) -> Option<OutputChunk> {
        let sessions = self.sessions.read();
        let session_hub = sessions.get(session_id)?.clone();
        drop(sessions);

        let mut hub = session_hub.write();
        let chunk = hub.buffer.push(data);
        let _ = hub.sender.send(chunk.clone());
        Some(chunk)
    }
}
```

pub fn attach(
    &self,
    session_id: &str,
    after_sequence: Option<u64>,
) -> Result<(ReplayResult, broadcast::Receiver<OutputChunk>), PtyError> {
    if !self.pty_manager.has_session(session_id) {
        return Err(PtyError::SessionNotFound(session_id.to_string()));
    }
    self.output_hub
        .subscribe(session_id, after_sequence)
        .ok_or_else(|| PtyError::SessionNotFound(session_id.to_string()))
}

### 2.4 Stream Pump Deduplication & Lag Gap Handling (`src-tauri/src/daemon/server.rs`)

In `DaemonServer::pump_stream` ([`server.rs:274-325`](src-tauri/src/daemon/server.rs)):
1. Client is sent the initial `AttachOk` / `AttachGap` / `AttachUpToDate` with `history_end_sequence = H`.
2. As live `OutputChunk` items arrive from `rx.recv()`:
   - If `chunk.sequence <= H`, discard (it was already delivered in the initial snapshot).
   - If `chunk.sequence > H`, forward as `DaemonStreamMessage::Output { session_id, sequence: chunk.sequence, data }`.
3. On `broadcast::error::RecvError::Lagged(_)`:
   - Call `hub.subscribe(&session_id, Some(last_emitted_sequence))`.
   - Send `DaemonStreamMessage::ReplayGap` with recovered chunks and update `last_emitted_sequence = new_snapshot.end_sequence`.

### 2.5 Isolated Process Group Close (`src-tauri/src/terminal/pty.rs`)
- In `PtyManager::close_session` ([`pty.rs:217-290`](src-tauri/src/terminal/pty.rs)):
  - Retain isolated process group signaling (`libc::kill(-(pid as i32), SIGTERM)` in [`session.rs:198`](src-tauri/src/terminal/session.rs)).
  - Ensure `close_session(session_id)` removes only `session_id` from `self.sessions` and `output_hub`, without closing the daemon listener or touching sibling sessions.
